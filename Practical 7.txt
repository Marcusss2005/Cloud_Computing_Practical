Enable Required APIs (GUI)

Select APIs & Services → Library
3.
Search for Cloud Build API
4.

6.
Go back and search for Artifact Registry API
Artifact means Docker Image
7.
Select Artifact Registry API
8.
It shows Enabled
9.
Click on APIs & Services
10. Search Artifact Registry in search box and select
11. Click on Create repository button
12. For your region open IAM & Admin → Organization Policies in new tab
13. Select View active policies
14. Search for below service and select
15. Select anyone which is allowed (i.e. us-west1)
16. Click on Repositories
17. You can find
18. Click on button to Activate Cloud Shell
19. Create a project folder
mkdir my-docker-app
cd my-docker-app
20. Create a Dockerfile (GUI + Editor)
Click on Open Editor
21. Select my-docker-app folder and click on new file icon
22. Enter file name as: Dockerfile
23. Write code below in that file
# Use official Python image
FROM python:3.10-slim
# Set working directory
WORKDIR /app
# Copy files
COPY . .
# Install dependencies
RUN pip install flask
# Expose port
EXPOSE 8080
# Run app
CMD ["python", "app.py"]
24. Select my-docker-app folder and click on new file icon – Give file
name as app.py
25. Write below code
from flask import Flask
app = Flask(__name__)
@app.route("/")
def hello():
 return "Hello from Docker on GCP!"
if __name__ == "__main__":
 app.run(host="0.0.0.0", port=8080)
26. Click on Open Terminal
27. Write below code: use your PROJECT_ID from skills.google
gcloud builds submit . 
--tag
europe-west1-
